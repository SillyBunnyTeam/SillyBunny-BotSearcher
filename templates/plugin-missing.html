Server half not installed

BotSearcher comes in two halves. The extension is installed — this part — but the server half is missing, and searching needs it. The card sites do not allow a browser to call them directly, so your own server has to make the requests.

  1. From your SillyBunny folder, install the plugin:

    bun plugins.js install https://github.com/platberlitz/SillyBunny-BotSearcher

  2. Open config.yaml and set both of these:

    enableServerPlugins: true
enableServerPluginsAutoUpdate: false

  3. Restart SillyBunny, then come back here and press Recheck.

Turning auto-update off is deliberate: with it on, every start pulls the latest code for each plugin and runs it. Updating on purpose, after reading what changed, is the safer habit.
