Server plugin not found

The frontend extension is installed, but BotSearcher could not find its server plugin. Both components are required for search.

  1. From your SillyBunny folder, install the server plugin:

    bun plugins.js install https://github.com/platberlitz/SillyBunny-BotSearcher

  2. Open config.yaml and set these values:

    enableServerPlugins: true
enableServerPluginsAutoUpdate: false

  3. Restart SillyBunny, then select Check again.

enableServerPluginsAutoUpdate: false keeps server-plugin updates manual so you can review changes before installing them.
